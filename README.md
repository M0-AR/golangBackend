
# Golang Backend Service

## Overview

This project is a backend service developed in Go that provides API endpoints for user signup and a dashboard. It's built with the Echo framework and uses MongoDB for data storage. The service is designed to be containerized with Docker and deployed using a GitLab CI/CD pipeline.

This document provides a comprehensive overview of the project, including its features, tech stack, and instructions for getting started, configuration, building, running, testing, and deployment. It is intended for a wide audience, including developers, DevOps engineers, and business stakeholders.

## Features

*   **User Signup:** Provides an endpoint for new users to create an account.
*   **Dashboard:** Offers a dashboard with relevant data for authenticated users.
*   **RESTful API:** Exposes a clean and well-structured RESTful API for easy integration with other services.
*   **Containerized:** The application is fully containerized with Docker, making it easy to build, ship, and run in any environment.
*   **CI/CD:** A GitLab CI/CD pipeline is in place to automate the build, test, and deployment process.

## Getting Started

Follow these instructions to get the project up and running on your local machine.

### Prerequisites

*   Go 1.17 or higher
*   Docker
*   MongoDB

### Installation

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/B1gDaddyKane/golangBackend.git
    ```
2.  **Navigate to the project directory:**
    ```bash
    cd golangBackend
    ```
3.  **Install dependencies:**
    ```bash
    go mod download
    ```

## Configuration

The application is configured using a `config.json` file located in the `lib/config` directory. This file includes settings for the host, port, and MongoDB connection.

| Key                             | Type   | Description                   |
| ------------------------------- | ------ | ----------------------------- |
| `host.address`                  | string | The host address for the      |
| `host.port`                     | int    | The port for the server       |
| `database.mongodb.timeout`      | int    | The timeout for the database  |
| `database.mongodb.dbname`       | string | The name of the database      |
| `database.mongodb.user`         | string | The username for the database |
| `database.mongodb.password`     | string | The password for the database |
| `database.mongodb.host`         | string | The host for the database     |
| `database.mongodb.port`         | string | The port for the database     |

## Building and Running

### Running Locally

To run the application locally, use the following command:

```bash
go run main.go
```

The server will start on the host and port specified in the `config.json` file.

### Building and Running with Docker

To build and run the application with Docker, use the following commands:

1.  **Build the Docker image:**
    ```bash
    docker build -t golang-backend .
    ```
2.  **Run the Docker container:**
    ```bash
    docker run -p 10000:10000 golang-backend
    ```

## Testing

```bash
go test ./...
```

## Deployment

The application is deployed using a GitLab CI/CD pipeline. The pipeline is configured in the `.gitlab-ci.yml` file and includes the following stages:

*   **build:** Compiles the Go application.
*   **publish:** Builds and pushes a Docker image to the GitLab container registry.
*   **deploy:** Deploys the Docker image to a server.

The pipeline is triggered on every push to the `main` or `deploy` branches.

## API Endpoints

The following are the available API endpoints:

*   `POST /signup`: Creates a new user.
*   `GET /dashboard`: Retrieves dashboard data.
